Три года дневных выдач потребкредитов, млн ₽. На последнем квартале виден уверенный рост, команда хочет масштабировать канал. Проверь тренд с учётом сезонности.

Проверяю. В дневном ряду выдач одновременно живут три цикла: годовой, внутримесячный (дни выплат) и недельный. Пока они не сняты, любой тренд — иллюзия. План:

  1. Сравню календарные кварталы по суммам выдач — то сравнение, из которого получен рост.
  2. Оценю недельный профиль по отношению ряда к скользящему среднему за 7 дней, годовой — по месяцам, внутримесячный — по дням месяца.
  3. Разделю ряд на все три профиля и посчитаю тренд по очищенному ряду.

Автоматический вывод

Управленческий смысл: масштабировать нечего — объём выдач снижается третий год подряд. Рост IV квартала повторяется каждый год и к качеству канала отношения не имеет.

import numpy as np, pandas as pd s = pd.read_csv("issues_daily_3y.csv", parse_dates=["date"]).set_index("date").amount_mln_rub q = s.resample("QE").sum() # суммы за календарные кварталы print("IV кв. 2025 к III кв. 2025:", q["2025-12-31"] / q["2025-09-30"] - 1) print("IV кв. 2025 к IV кв. 2024:", q["2025-12-31"] / q["2024-12-31"] - 1) wk = (s / s.rolling(7, center=True).mean()).groupby(s.index.dayofweek).median() s1 = s / s.index.dayofweek.map(wk / wk.mean()) # снимаем неделю yr = (s1 / s1.rolling(365, center=True).mean()).groupby(s1.index.month).median() s2 = s1 / s1.index.month.map(yr / yr.mean()) # снимаем год mth = (s2 / s2.rolling(31, center=True).mean()).groupby(s2.index.day).median() adj = s2 / s2.index.day.map(mth / mth.mean()) # снимаем дни выплат b, a = np.polyfit(np.arange(len(adj)), adj.values, 1) print("тренд adj, 3 года:", b * (len(adj) - 1) / a)
Все числа и графики на странице рассчитаны в браузере по выгрузке issues_daily_3y.csv — три года дневных выдач потребительских кредитов. Данные синтетические: структура и порядок величин типовые для розничного банка, значения условные.
