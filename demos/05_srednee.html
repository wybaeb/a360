Средний срок рассмотрения заявки на кредит для МСБ — 2,1 дня при нормативе 3 дня. В отчёте написано «норматив выполнен». Проверь по всей выборке заявок за квартал.

Проверяю. Среднее по такому процессу почти всегда обманывает: заявки идут двумя разными маршрутами. План:

  1. Построю распределение сроков по всем заявкам квартала, а не одно число.
  2. Посчитаю медиану и 90-й перцентиль — что чувствует не «средний», а реальный клиент.
  3. Свяжу срок ожидания с конверсией в выдачу — сколько это стоит.

Управленческий смысл: норматив по среднему выполняется ровно потому, что 71 % заявок проходит автоскоринг за часы. Он маскирует ручной маршрут, в котором клиент ждёт неделю. Правильный норматив — по 90-му перцентилю, а не по среднему.

import pandas as pd, numpy as np df = pd.read_csv("sme_applications_q.csv") # tat_days, issued print("среднее :", df.tat_days.mean().round(2)) print("медиана :", df.tat_days.median().round(2)) print("p90 :", df.tat_days.quantile(0.9).round(2)) print("доля > норматива:", (df.tat_days > 3).mean().round(3)) bins = [0, 1, 3, 7, 99] df["bucket"] = pd.cut(df.tat_days, bins, labels=["<1 дн", "1–3 дн", "3–7 дн", ">7 дн"]) print(df.groupby("bucket").agg(n=("issued", "size"), conv=("issued", "mean")).round(3))
Демонстрационный расчёт на синтетическом датасете. Структура и порядок величин — типовые для розничного банка, конкретные цифры условные.
