Проект по варианту: от каркаса до презентации

Три направления — продукт, процесс, бизнес-инициатива — по три варианта в каждом. По своему варианту участник проходит каркас проекта, собирает конфигурацию дерева метрик с оценкой скорости и цены данных, получает от ассистента мини-инструмент расчёта параметров на нескольких выгрузках, затем мини-инструмент финансовой модели с графиком, и собирает презентацию проекта.

Вариантов: 9 Шагов: 5 Нужен: ассистент в браузере Итог: презентация проекта

Как проходить

  1. Выберите вариант — направление и номер. Каркас проекта по варианту заполнен, его можно уточнить.
  2. Соберите конфигурацию дерева: для каждого входа итоговой метрики выберите источник данных. Страница показывает срок первого значения, стоимость и интегральную оценку конфигурации.
  3. Скачайте файлы выбранных источников и скопируйте промпт. Ассистент возвращает код расчёта: вставьте его в тренажёр и нажмите «Скачать мой мини-инструмент» — получится один HTML-файл. Откройте его, выберите файлы одной кнопкой — инструмент посчитает параметры проекта и сверит расчёт ассистента с контрольным.
  4. Финансовая модель: второй промпт с параметрами — ассистент возвращает код расчёта потока; вставьте его, скачайте инструмент финансовой модели, откройте: окупаемость, NPV, график SVG с кнопкой сохранения. Загрузите SVG сюда.
  5. Презентация собирается из всего сделанного: слайды листаются здесь и скачиваются одним HTML-файлом.

Введённое сохраняется в браузере отдельно для каждого варианта. Скачанный инструмент открывается двойным щелчком в любом браузере. Если код ассистента не собрался, инструмент показывает контрольный расчёт, и занятие продолжается.

Шаг 1

Каркас проекта

Семь элементов каркаса: проблема → метрика → данные → инструмент → анализ → вывод → эффект. По варианту они заполнены; уточните формулировки языком своего подразделения — проблема должна содержать показатель с числом, источник и то, что меняем.

Шаг 2

Дерево метрик и конфигурация источников

Итоговая метрика эффекта считается из входов; каждый вход можно получить из двух источников с разной скоростью и ценой. Срок первого значения метрики определяется самым медленным входом, стоимость складывается, интегральная оценка учитывает и то, и другое.

Шаг 3

Мини-инструмент расчёта параметров

Мини-инструмент читает несколько CSV одной кнопкой, считает входы дерева и три параметра финансовой модели, рисует график. Расчёт входов по формулам дерева пишет ассистент по промпту ниже; тренажёр собирает из его ответа готовый инструмент одним файлом. Расчёт выполняется в браузере, данные никуда не отправляются.
