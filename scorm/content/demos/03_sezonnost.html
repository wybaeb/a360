Три года дневных выдач потребкредитов, млн ₽. На последнем квартале виден уверенный рост, команда хочет масштабировать канал. Проверь тренд с учётом сезонности.

Проверяю. В дневном ряду выдач одновременно живут три цикла: годовой, внутримесячный (дни зарплат) и недельный. Пока они не сняты, любой тренд — иллюзия. План:

  1. Оценю недельный профиль по отношению ряда к скользящему среднему за 7 дней.
  2. Оценю годовой профиль по месяцам и внутримесячный — по дням месяца.
  3. Разделю ряд на все три профиля и посчитаю тренд по очищенному ряду.

Автоматический вывод

Управленческий смысл: масштабировать нечего — канал теряет объём третий год подряд. Рост IV квартала повторяется каждый год и к качеству канала отношения не имеет.

import pandas as pd, statsmodels.api as sm s = pd.read_csv("loans_daily_3y.csv", parse_dates=["date"]).set_index("date").amount wk = (s / s.rolling(7, center=True).mean()).groupby(s.index.dayofweek).median() s1 = s / s.index.dayofweek.map(wk) # снимаем неделю yr = (s1 / s1.rolling(365, center=True).mean()).groupby(s1.index.month).median() s2 = s1 / s1.index.month.map(yr) # снимаем год mth = (s2 / s2.rolling(31, center=True).mean()).groupby(s2.index.day).median() adj = s2 / s2.index.day.map(mth) # снимаем дни зарплат print("Q4/Q3 сырой ряд :", (s['2025-10':].mean()/s['2025-07':'2025-09'].mean()-1)) print("тренд adj, 3 года:", sm.OLS(adj.values, sm.add_constant(range(len(adj)))).fit().params[1]*len(adj))
Демонстрационный расчёт на синтетическом датасете. Структура и порядок величин — типовые для розничного банка, конкретные цифры условные.
