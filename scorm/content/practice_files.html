Папка практики: скачать без git

Та же папка, что в репозитории практики, — файл за файлом. Для машин, где git и сайт репозитория недоступны: скачайте архив целиком или нужные файлы по отдельности и положите их в одну папку с той же структурой — в JupyterHub, VS Code или просто на диск.

Файлов: 86 Всего: 8,0 МБ Комплектов на кейс: 12

1Три способа забрать папку

  1. Комплект на кейс.

    Архив «всё для кейса»: папка кейса и ровно те файлы данных и общих модулей, которые ей нужны, со структурой папок. Ссылки — в таблице ниже и у каждой папки в списке. Распакуйте — и кейс готов к запуску.

  2. По одному файлу.

    Ниже список всех файлов по папкам. Щелчок по имени сохраняет файл; плашка «на сайте» открывает README или тетрадь для чтения прямо здесь. Сохраняйте структуру: тетради ищут общие модули в tools/ и выгрузки в data/ на уровень выше себя, поэтому папка кейса, tools/ и data/ должны лежать рядом в одной родительской папке.

  3. Через git — на машине, где он есть и репозиторий доступен: 
    git clone https://github.com/wybaeb/bank-analytics-workshop.git

Все варианты работы без репозитория, включая JupyterHub и кейсы без стенда, — на странице «Если не открывается GitHub».

2Как положить в JupyterHub

  1. В файловой панели хаба создайте папку bank-analytics-workshop.
  2. Внутри неё — папки с теми же именами, что здесь: папку кейса, tools/ и data/ с вложенными папками.
  3. Кнопкой Upload загрузите файлы в каждую из папок. Тетрадь открывается двойным щелчком; вверху — Restart Kernel → Run All.
  4. Для тетрадей с базой нужны переменные окружения подключения — их задаёт администратор хаба, см. второй раздел инструкции установки.

Файл .env.example — образец настроек для локального стенда; в хабе он не нужен.
