Если не открывается GitHub

В корпоративной сети сайт репозитория github.com часто закрыт, а страницы материалов на github.io открываются. Все файлы практики поэтому продублированы здесь, на сайте: их можно читать, скачивать по одному или комплектом на кейс и загружать в JupyterHub. Ни одного действия на github.com для прохождения практики не требуется.

Читать: README и тетради на сайте Скачать: файл, комплект на кейс, вся папка Запустить: JupyterHub или свой компьютер

1Как понять, что дело в сети

Признаки одни и те же: команда git clone заканчивается ошибкой соединения, ссылка на репозиторий в браузере не открывается или показывает страницу-заглушку, кнопка «Download ZIP» на сайте репозитория недоступна. При этом страницы материалов и тренажёры на этом сайте работают. Ничего чинить не нужно: дальше — как обойтись без репозитория.

Как устроены ссылки в материалах

Рядом с каждой ссылкой на файл репозитория стоят две плашки: на сайте открывает читаемую копию здесь, скачать сохраняет файл. Если основная ссылка не открывается — используйте плашки.

2Где взять файлы

  1. Комплект на кейс. На странице файлов практики у каждого кейса есть архив «всё для кейса»: папка кейса и ровно те файлы данных и модулей, которые ей нужны, со структурой папок. От 7 КБ до 630 КБ. Распакуйте — и кейс готов к запуску.
  2. По одному файлу. На той же странице все файлы перечислены по папкам; щелчок по имени сохраняет файл. Так удобно взять одну выгрузку или один промпт.
  3. Вся папка целиком. Внизу той же страницы — архив всего репозитория, 2,5 МБ. Нужен только тем, кто разворачивает стенд у себя.

Если архивы на вашей машине не скачиваются или не распаковываются — берите файлы по одному: это те же файлы.

3Читать, не скачивая

README каждого кейса, инструкции установки и все тетради с результатами выполнения собраны страницами сайта — открываются как обычные страницы, с телефона тоже. Ссылки «на сайте» ведут именно туда. Мини-инструменты кейсов (файлы .html) открываются в браузере прямо с сайта.

Тетрадь на сайте — это просмотр: код и результаты видны, запустить его нельзя. Для запуска тетрадь скачивают и открывают в JupyterHub или VS Code.

4Запустить в JupyterHub

  1. В файловой панели хаба создайте папку bank-analytics-workshop.
  2. Распакуйте комплект кейса на своём компьютере и загрузите папки кнопкой Upload, сохраняя структуру: папка кейса, tools/ и data/ лежат рядом. Тетради ищут их на уровень выше себя.
  3. Откройте тетрадь, вверху — Restart Kernel → Run All.
  4. Тетрадям с базой данных нужны переменные подключения; их задаёт администратор хаба по инструкции установки, раздел «В JupyterHub». Пароль в тетрадь не вписывают.

5Что работает без стенда, pip и Docker

Если закрыт сайт репозитория, обычно закрыты и установка библиотек из интернета, и загрузка образов Docker. Стенд на своём компьютере тогда не поднять — но большая часть практики в нём и не нуждается.

6Ассистент

Веб-версия ассистента для кейсов с промптами открывается в браузере и репозитория не требует. Для тетрадей, которые обращаются к модели из кода, нужен ключ и сетевой доступ к API — их выдаёт администратор; адреса перечислены в инструкции установки. Если ключа нет, тетради этих двух кейсов читают как просмотр на сайте: результаты выполнения в них сохранены.

7Если не помогло

Напишите куратору потока, указав: какую страницу или файл открывали, что увидели вместо результата (текст ошибки или снимок экрана) и с какой машины — рабочей или личной. С этим ответ приходит быстрее: обычно достаточно прислать один нужный файл.
