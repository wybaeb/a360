# 3. Сезонность: рост, которого нет · GigaChat-2 · прогон 3 · naive

Рассмотрим данные и посчитаем изменение выдачи потребительских кредитов (в млн руб.) за каждый квартал отдельно.

### Квартал I

- **2023**:  
$4145 + 3414 + 3289 = 10848$
- **2024**:  
$3862 + 3331 + 3027 = 10220$
- **2025**:  
$3708 + 3022 + 2809 = 9540$

**Изменение:**  
$10220 - 10848 = -628\ ($минус $628)$  
$9540 - 10220 = -680\ ($минус $680)$

За первый квартал наблюдаем падение объёма кредитования примерно на 628–680 млн рублей.

---

### Квартал II

- **2023**:  
$2574 + 2414 + 2224 = 7212$
- **2024**:  
$2505 + 2281 + 2038 = 6824$
- **2025**:  
$2351 + 2114 + 1916 = 6382$

**Изменение:**  
$6824 - 7212 = -388\ ($минус $388)$  
$6382 - 6824 = -442\ ($минус $442)$

Падение заметно усиливается: во втором квартале объём кредитования сократился ещё сильнее — около 442 млн рублей.

---

### Квартал III

- **2023**:  
$2401 + 2782 + 3131 = 8315$
- **2024**:  
$2316 + 2686 + 2960 = 7963$
- **2025**:  
$2159 + 2435 + 2801 = 7496$

**Изменение:**  
$7963 - 8315 = -353\ ($минус $353)$  
$7496 - 7963 = -468\ ($минус $468)$

Сокращение продолжается, однако темп снижения несколько замедлился относительно предыдущих кварталов.

### Квартал IV

- **2023**:  
$3683 + 3950 + 4051 = 11685$
- **2024**:  
$3468 + 3599 + 3758 = 10826$
- **2025**:  
$3276 + 3387 + 3417 = 10081$

**Изменение:**  
$10826 - 11685 = -859\ ($минус $859)$  
$10081 - 10826 = -746\ ($минус $746)$

И наконец, четвёртый квартал показывает самый значительный спад: почти 859 млн рублей во второй год и 746 млн рублей в третий год.

---

## Итоговый вывод:
Рост по итогам IV квартала действительно присутствует, однако носит исключительно локальный характер. Сравнивая итоговые показатели каждого года:

- **2023 год**: $11685$ млн рублей
- **2024 год**: $10826$ млн рублей (-859)
- **2025 год**: $10081$ млн рублей (-746)

При этом даже последний год демонстрирует снижение суммарной суммы выдач по сравнению с предыдущими годами, что прямо противоречит гипотезе роста. Таким образом, говорить о стабильном росте выдачи потребительских кредитов нельзя. Более того, чётко видно, что происходит устойчивое сокращение кредитного портфеля и потребности клиентов в займах.

Рекомендация команде: важно проанализировать причины такого падения спроса и рассмотреть меры по улучшению ситуации.
