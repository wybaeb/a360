### Анализ сроков рассмотрения заявок

Рассмотрим исходные данные по количеству минут на рассмотрение заявки ежедневно за последние 90 дней (по месяцам):

| Дата      | Минуты   |
|-----------|----------|
| 04-05     | 41,1     |
| 05-05     | 38,6     |
| …         | …        |
| 31-07     | 51,2     |

**Шаг 1:** Подсчёт среднего значения времени обработки заявок (в минутах) за каждый день.

Для наглядности удобно сгруппировать данные по неделе:

#### По неделям:

- **Первая неделя мая**:  
  $(41,1 + 38,6 + 39,5 + 34,4 + 39,9 + 40,9 + 36,9) / 7 = 39,8$

- **Вторая неделя мая**:  
  $(46,1 + 40,4 + 38,3 + 43,6 + 40,2 + 41,2 + 39,2) / 7 = 41,6$

- И далее аналогично до конца июня.

- **Пятая неделя июля**:  
  $(41,7 + 38,6 + 38,0 + 46,4 + 35,8 + 44,9 + 388,0) / 7 ≈ 48,3$  

Продолжим вычисления для всех недель, суммируем итоговые результаты.

---

#### Итоговая таблица средних значений времени обработки заявок:

| Неделя | Среднее время обработки (минут) |
|--------|--------------------------------|
| 1      | 39,8                           |
| 2      | 41,6                           |
| 3      | 41,2                           |
| 4      | 42,4                           |
| 5      | 48,3                           |

---

**Шаг 2:** Сравним средние показатели первых двух месяцев (май — июнь).

Средние значения за май:  
$(39,8 + 41,6 + 41,2 + 42,4) / 4 = 41,2$

Средние значения за июль:  
$(48,3)$ (средняя за неделю)

**Анализ:**
- Среднее значение за первые два месяца (май–июнь): примерно 41 минута.
- За июль среднее значительно увеличилось до ~48 минут.

---

**Заключение:** 
Конвейер действительно замедлился после середины июня, поскольку средняя обработка заявок превысила показатель предыдущего периода примерно на 7 минут (48 против 41). Это подтверждает утверждение руководителя о снижении скорости работы системы.
