# 4. Низкая база: проценты без базы ничего не значат · GigaChat-2 · прогон 3 · check

Вердикт судьи: совпадает с эталоном
Элементы разбора: {"выбран пересчёт в деньги и доли": true, "критерий назван": true, "ошибка названа": true}

---

1. Выбрана проверка **пересчёта процентов в абсолютный прирост и в доли рынка**  
   Причина выбора: сравнение темпов роста банков некорректно, поскольку банки имеют разную масштабность бизнеса. Если одна организация гораздо крупнее другой, одинаковый процентный рост означает разное количество выданных ипотек.

2. Формула расчёта:  
$$D_{abs}=\frac{\text{now\_bn\_rub}-\text{was\_bn\_rub}}{\text{was\_bn\_rub}} \times 100\%$$

   Для анализа долей рынка:  
$$M=\frac{\text{now\_bn\_rub}}{\sum_{\text{all\ banks}}\text{now\_bn\_rub}} \times 100\%$$

3. Подтверждение гипотезы: наши выдача и доля рынка выросли больше остальных, несмотря на меньший относительный прирост. Опровержение: другие игроки демонстрируют больший реальный прирост ипотечных кредитов и большую долю рынка по сравнению с нами.
   
4. Типовая ошибка, которую устраняет проверка: **ошибка масштаба**, когда относительные показатели игнорируют различия в размерах компаний.
