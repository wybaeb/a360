### **Шаг 1. Анализ исходных данных**

Даны временные показатели обработки заявок (в минутах) за последние 90 дней. Нам нужно посчитать среднее время обработки заявок по дням и выявить динамику изменения среднего значения.

### **Шаг 2. Подготовка данных**
Создадим таблицу данных:

| Дата         | Время |
|--------------|-------|
| 04-05        | 41.1  |
| 05-05        | 38.6  |
| …           | …    |
| 31-07        | 51.2  |

### **Шаг 3. Вычисление средних значений**
Вычислим средние значения времени обработки заявок по каждой неделе:

- Неделя 1:  
$ (41.1 + 38.6 + 39.5 + 34.4 + 39.9 + 40.9 + 36.9 + 46.1 + 40.4 + 38.3 + 43.6 + 40.2) / 12 = 40.5 $

- Неделя 2:  
$ (41.2 + 39.2 + 41.4 + 46.2 + 43.8 + 44.3 + 41.7 + 36.1 + 40.2 + 45.6 + 45.7 + 45.3) / 12 = 42.8 $

…

### **Шаг 4. Построение графика и вычисление общего тренда**
Для наглядности представим данные в виде графика:

```
import matplotlib.pyplot as plt

# Данные
data = {
    'date': ['04-05', '05-05', ..., '31-07'],
    'time': [41.1, 38.6, ..., 51.2]
}

fig, ax = plt.subplots()
ax.plot(data['date'], data['time'])
plt.title('Среднее время обработки заявок')
plt.xlabel('Дата')
plt.ylabel('Время (минуты)')
plt.show()
```

### **Шаг 5. Анализ результатов**
Из построенного графика видно, что начиная примерно с середины июня (около 16-го числа), наблюдается рост среднего времени обработки заявок. Конкретный рост фиксируется около недели с 16 по 22 июня (где средний показатель резко вырос до ~296 минут). После этого периода график показывает значительное снижение, вплоть до рекордно низкого показателя — 35,8 минут (28-06).

Однако позже снова наблюдаются резкие скачки (особенно на период после 25 июля), где максимальное значение достигает почти 512 минут.

### **Заключение**
Да, руководитель прав: наблюдается замедление работы конвейера с начала июня, пиковый рост приходится на неделю с 16 по 22 июня, после чего ситуация стабилизировалась и затем улучшилась. Однако второй всплеск в конце июля привел к еще большему ухудшению показателей.

Таким образом, руководителю стоит обратить внимание именно на июньские проблемы и июльский скачок длительности обработки заявок.
