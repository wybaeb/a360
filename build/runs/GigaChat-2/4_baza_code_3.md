Вот решение задачи проверки пересчёта темпов прироста (темпов роста) выданных кредитов в абсолютные значения (млрд рублей) и относительные проценты (доля рынка):

```python
import pandas as pd
import numpy as np

# Загружаем файл
df = pd.read_csv('data.csv')

# Проверяем структуру данных и типы столбцов
print("Структура загруженных данных:")
print(df.info())

# Добавляем новый столбец 'growth_rate' с приростом в процентах от предыдущего года
df['growth_rate'] = ((df['now_bn_rub'] / df['was_bn_rub']) - 1) * 100

# Создаём новые столбцы для расчёта абсолютной суммы прироста
df['absolute_growth'] = df['now_bn_rub'] - df['was_bn_rub']

# Выводим итоговую таблицу с приростом в рублях и долях рынка
print("\nТаблица сравнения прироста (в млн руб., %):")
print(df[['bank', 'was_bn_rub', 'now_bn_rub', 'absolute_growth', 'growth_rate']])

# Формулируем строку вывода, которую можно использовать в отчёте
report_line = f"""|
- Темпы прироста (рост) по банку {df['bank'].values[0]} составили:
   - Абсолютный прирост: **{int(df['absolute_growth'].values[0])} млрд руб.**  
   - Прирост относительно прошлого периода: **{round(df['growth_rate'].values[0], 2)}%** 
"""

# Печать итогового результата
print(report_line)
```

### Объяснение каждого шага:

1. Импортируем библиотеки `pandas` и `numpy`.
2. Читаем файл CSV в DataFrame с помощью функции `pd.read_csv()`.
3. Используем метод `.info()` для быстрого анализа типов данных и количества записей.
4. Рассчитываем темпы прироста (рост) банка относительно предыдущего года через формулу `(текущие_данные / прошлые_данные) - 1`, умноженную на 100%, чтобы получить процентное выражение изменения.
5. Вычисляем абсолютную разницу между значениями прошлых и текущих месяцев, получив значение прироста в рублях (`absolute_growth`).
6. Выводим итоговую таблицу с подробными показателями, включая исходные данные и рассчитанные показатели.
7. Формируем одну строку текста, которая подходит для оформления отчета.
8. Результат выводится в консоль вместе с готовой строкой для вставки в отчет.
