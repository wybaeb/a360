Вот решение на основе Pandas и NumPy, которое рассчитывает медиану и 90-й процентиль столбца `tat_days`, проверяя корректность структуры данных и выбросов.

```python
import pandas as pd
import numpy as np

# Загружаем файл CSV
df = pd.read_csv('data.csv')

# Проверяем структуру файла
print("Структура загруженных данных:")
print(df.info())

# Проверяем наличие пропущенных значений
print("\nПропущенные значения:")
print(df.isnull().sum())

# Удалим пустые строки и строки с некорректными значениями
df_cleaned = df.dropna(subset=['app_id', 'tat_days'])

# Проверим количество записей после очистки
print(f"\nКоличество строк после удаления пропущенных значений: {len(df_cleaned)}")

# Анализируем распределение срока рассмотрения заявки
median_tat = df_cleaned['tat_days'].median()
p90_tat = df_cleaned['tat_days'].quantile(0.9)

# Выводим результаты анализа
print(f"Медиана срока рассмотрения заявки: {median_tat:.2f}")
print(f"90-й перцентиль срока рассмотрения заявки: {p90_tat:.2f}")

# Создаём строку для отчёта
report_string = f"Анализ распределения сроков рассмотрения заявок\nМедиана: {median_tat:.2f}\n90-й перцентиль: {p90_tat:.2f}"
```

### Объяснение шагов:

- **Загрузка файла:** используем функцию `pd.read_csv()`.
- **Проверка структуры:** выводим информацию о структуре таблицы (`info()`).
- **Проверка наличия пропущенных значений:** функция `isnull().sum()` покажет количество отсутствующих значений по каждому столбцу.
- **Удаление пропусков:** удаляем записи с пустыми значениями в ключевых столбцах.
- **Расчёт медианы и 90-го перцентиля:** применяем функции `.median()` и `.quantile(0.9)` для получения соответствующих показателей.
- **Формирование отчета:** выводим результаты расчётов и формируем строку для последующего добавления в отчет.

### Итоговый результат:

Запустив скрипт, вы получите числовые показатели (например):

```
Медиана срока рассмотрения заявки: 5.67
90-й перцентиль срока рассмотрения заявки: 10.33
Анализ распределения сроков рассмотрения заявок
Медиана: 5.67
90-й перцентиль: 10.33
```
