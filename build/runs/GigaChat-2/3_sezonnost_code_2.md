Вот решение на Python с использованием библиотеки `pandas` и стандартных функций для снятия сезонности, сравнения сопоставимых периодов и формирования вывода для отчета:

### Шаги анализа:
1. Загрузка данных.
2. Преобразование даты в корректный тип (`datetime`) и добавление временных столбцов (год, месяц).
3. Снятие сезонности (вычитание скользящего среднего за соответствующий день месяца).
4. Формирование отчетной таблицы, содержащей значения до и после удаления сезонности, и вычисление относительного изменения («год к году»).
5. Вывод итогового числа и строки, которую можно вставить в отчет.

```python
import pandas as pd
import numpy as np

# Загружаем данные
data = pd.read_csv('your_data.csv')

# Проверяем структуру загруженных данных
print("Загруженные данные:")
print(data.head())

# Преобразуем дату в datetime и добавляем необходимые временные метки
data['date'] = pd.to_datetime(data['date'])
data['year'] = data['date'].dt.year
data['month'] = data['date'].dt.month
data['day_of_month'] = data['date'].dt.day

# Вычисляем скользящее среднее за последние 7 дней (для снятия сезонности)
data['seasonal_adjustment'] = data.groupby(['month', 'day_of_month'])['amount_mln_rub'].transform(lambda x: x.rolling(7).mean())

# Вычитаем скользящее среднее, чтобы снять сезонность
data['adjusted_amount'] = data['amount_mln_rub'] - data['seasonal_adjustment']

# Группируем по году и получаем количество месяцев
grouped_by_year = data.groupby('year').agg({
    'amount_mln_rub': ['sum'],
    'adjusted_amount': ['sum']
})

# Названия агрегаций
grouped_by_year.columns = ['original_total', 'adjusted_total']

# Формируем таблицу для наглядного представления
report_table = grouped_by_year.copy()
report_table['percent_change'] = ((report_table['adjusted_total'] / report_table['original_total']) * 100).round(2)
report_table['percent_change'] -= 100  # Получаем процентное изменение относительно предыдущего года
report_table.index.name = 'Year'

# Печать итоговой таблицы
print("\nОтчетная таблица:")
print(report_table)

# Выводим строку, которую можно вставить в отчет
report_string = f"""
Сравнение годовых показателей за сопоставимые периоды (после сезонной коррекции):
Годовая сумма выдачи потребительских кредитов:
До сезонной коррекции: {report_table['original_total'].values[-1]:,.2f}
После сезонной коррекции: {report_table['adjusted_total'].values[-1]:,.2f}
Изменение %: {report_table['percent_change'].values[-1]:+.2f}%
"""

print("\nИтоговый вывод для отчета:")
print(report_string)
```

### Пояснения:
- Загружаем файл CSV.
- Преобразуем колонку `date` в корректный тип `datetime`, создавая новые поля для года, месяца и дня месяца.
- Для каждого дня месяца рассчитываем скользящее среднее за последние 7 дней, чтобы компенсировать влияние сезонности.
- Вычитаем полученное скользящее среднее из исходных значений, таким образом устраняя сезонную составляющую.
- Группируем данные по годам и считаем суммы до и после сезонной коррекции.
- Рассчитываем относительное изменение между этими суммами, выраженное в процентах от исходного показателя.
- Создаем отчетную таблицу и печатаем итоговые результаты, формируя вывод, подходящий для отчета.
