## 1. ЧТО ВИДНО БЕЗ ПРОВЕРКИ  
Среднее значение срока обработки 2,08 дня ниже норматива в 3 дня, поэтому напрашивается вывод, что норматив выполнен.

## 2. ЧТО ПОКАЗАЛА ПРОВЕРКА  
Однако проверка показала два важных момента:  
- Норматив нарушен для 25% заявок (вторая четверть распределения).  
- Двугорбый характер распределения означает наличие двух разных маршрутов обработки заявок («быстрая корзина» и «медленная корзина»).  
Из-за быстрого маршрута значительная часть заявок обрабатывается быстрее норматива, но остальные 25% задерживаются значительно дольше норматива.  

Для быстрой корзины средняя обработка составляет всего 0,2 дня (~5 часов), однако половина медленных заявок обрабатываются свыше 3 дней, причем некоторые даже до 7,9 дней.

Таким образом, норматив был выполнен лишь формально, без учета реального качества обслуживания.

## 3. КАК НАЗЫВАЕТСЯ ОШИБКА  
Ошибка называется **«ошибка выборки»** (sampling bias):  
Выбранный показатель (средний срок) дал ложное представление о реальности, потому что не учитывал разнородность групп заявок. 

Стоимость ошибки заключается в том, что банк недополучил порядка 6,6 млрд рублей дополнительного дохода от выданных кредитов, который мог бы получить при своевременной обработке всех заявок.

## 4. РЕШЕНИЕ  
Норматив должен задаваться отдельно для каждой группы заявок (например, средний срок по быстрой корзине и по медленной корзине). Для медленного маршрута нужно улучшить процессы, автоматизировать обработку, внедрить контроль сроков рассмотрения заявок и повысить мотивацию сотрудников для ускорения работы, чтобы избежать чрезмерного накопления долговых периодов ожидания клиентов.
