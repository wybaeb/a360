Вот решение задачи на Python с использованием библиотеки `pandas` и стандартной библиотеки `numpy`. Реализуем шаги анализа пошагово с подробными комментариями.

```python
import pandas as pd
import numpy as np

# Загружаем файл csv
df = pd.read_csv('data.csv')

# Проверим структуру данных
print("Количество строк:", len(df))
print("Колонки:", df.columns)

# Отфильтруем строки, где tat_days задано числовым значением
filtered_df = df.query('tat_days != "" & tat_days != " " & tat_days != "-"')

# Преобразуем столбец 'tat_days' в числовой тип
filtered_df['tat_days'] = filtered_df['tat_days'].astype(float)

# Анализируем выборку на предмет отсутствующих значений и ошибок типов
print(filtered_df.info())

# Получим медиану и 90-й перцентиль сроков рассмотрения заявок
median_tat = np.median(filtered_df['tat_days'])
ninety_perc_tat = np.percentile(filtered_df['tat_days'], 90)

# Выводим результаты в удобочитаемом виде
print(f"Медиана срока рассмотрения заявки: {median_tat:.2f} дней")
print(f"90-й перцентиль срока рассмотрения заявки: {ninety_perc_tat:.2f} дней")

# Сформулируем строку вывода для отчета
report_output = f"Анализ распределения сроков рассмотрения заявок:\nМедиана: {median_tat:.2f} дней\n90-й перцентиль: {ninety_perc_tat:.2f} дней"
```

### Пояснения шагов решения:

1. **Загрузка данных:**  
   Мы загружаем CSV-файл командой `pd.read_csv()`, проверяем количество строк и список колонок.
   
2. **Фильтрация строк:**  
   Используем метод `.query()` для фильтрации строк, где значение в поле `tat_days` содержит числа, исключая пустые строки и недопустимые символы.

3. **Преобразование типов:**  
   Преобразуем значения поля `tat_days` в числовой тип с помощью метода `.astype()`.

4. **Проверка пропущенных значений и корректности данных:**  
   Вызываем метод `.info()` для проверки наличия ошибок типов и пропущенных значений.

5. **Вычисление статистики:**  
   Применяем функции `np.median()` и `np.percentile()` для вычисления медианы и 90-го перцентиля.

6. **Формирование результата для отчёта:**  
   Форматируем вывод результатов в удобной форме для последующего включения в отчет.

**Пример результата вывода:**

```
Анализ распределения сроков рассмотрения заявок:
Медиана: 7.30 дней
90-й перцентиль: 15.50 дней
```
