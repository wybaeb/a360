# 5. Среднее: норматив выполнен, клиент ждёт неделю · GigaChat-2 · прогон 2 · check

Вердикт судьи: совпадает с эталоном
Элементы разбора: {"выбран анализ распределения": true, "критерий назван": true, "ошибка названа": true}

---

1. Выбрана проверка **«анализ распределения (медиана и перцентили)»** — подходит для оценки соответствия среднего значения реальному положению дел, поскольку возможна ситуация, когда малое количество записей значительно влияет на среднее значение, искажая реальную картину выполнения норматива.
   
2. Метод расчёта:
   Медиана вычисляется через нахождение центрального элемента упорядоченного множества значений. Перцентиль рассчитывается как процентное отношение числа наблюдений меньше заданного значения к общему числу наблюдений.
   
3. Подтверждение исходного вывода произойдет, если медиана срока рассмотрения окажется близкой к нормативному показателю 3 дня, а медианное распределение близко к 2,1 дню, совпадая с средним сроком. Опровержение вывода произойдёт, если медианное значение существенно превышает норматив либо наблюдается значительное расхождение между медианой и средним арифметическим показателем.

4. Проверка позволяет избежать ошибки **«искажённого восприятия среднего значения большой выборки малыми выбросами»**, которая легко возникает при анализе только среднего арифметического.
