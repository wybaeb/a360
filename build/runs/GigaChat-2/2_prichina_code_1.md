Напишем программу на Python с использованием библиотеки `pandas`, чтобы провести **корреляционный анализ** с фиксацией третьего показателя (`churn_pct`). 1. Загружаем файл в DataFrame.

4. Выводим результат корреляции и формуруем строку для отчёта.
