Рассчитаем темпы роста выдачи потребительских кредитов по кварталам за последние три года (2023–2025), чтобы подтвердить наличие устойчивого тренда на увеличение объемов кредитования в IV квартале каждого года.

### Годовая разбивка по кварталам:
- **I квартал**: январь + февраль + март  
- **II квартал**: апрель + май + июнь  
- **III квартал**: июль + август + сентябрь  
- **IV квартал**: октябрь + ноябрь + декабрь

#### Рассчитаем суммарную выдачу по каждому кварталу:
**2023 год:**
- I кв.: $4\,145 + 3\,414 + 3\,289 = 10\,848$ млн руб.
- II кв.: $2\,574 + 2\,414 + 2\,224 = 7\,212$ млн руб.
- III кв.: $2\,401 + 2\,782 + 3\,131 = 8\,314$ млн руб.
- IV кв.: $3\,683 + 3\,950 + 4\,051 = 11\,684$ млн руб.

**2024 год:**
- I кв.: $3\,862 + 3\,331 + 3\,027 = 10\,220$ млн руб.
- II кв.: $2\,505 + 2\,281 + 2\,038 = 6\,824$ млн руб.
- III кв.: $2\,316 + 2\,686 + 2\,960 = 7\,962$ млн руб.
- IV кв.: $3\,468 + 3\,599 + 3\,758 = 10\,825$ млн руб.

**2025 год:**
- I кв.: $3\,708 + 3\,022 + 2\,809 = 9\,539$ млн руб.
- II кв.: $2\,351 + 2\,114 + 1\,916 = 6\,381$ млн руб.
- III кв.: $2\,159 + 2\,435 + 2\,801 = 7\,395$ млн руб.
- IV кв.: $3\,276 + 3\,387 + 3\,417 = 10\,080$ млн руб.

---

### Сравним динамику между каждым годом:

| Период       | Выдача, млн рублей |
|--------------|--------------------|
| 2023 Q4      | 11 684             |
| 2024 Q4 (+Y/Y)| 10 825 (-7,3%)     |
| 2025 Q4 (+Y/Y)| 10 080 (-6,9%)     |

Несмотря на ежегодное снижение объема относительно предыдущего года ($-7,3\%$, $-6,9\%$), объем четвертого квартала стабильно превышает показатели всех остальных трех кварталов внутри одного календарного года:

- По сравнению с I кварталом — примерно в $+10\%$-$+20\%$.
- По сравнению со II кварталом — около $+50\%$-$+70\%$.
- По сравнению с III кварталом — порядка $+30\%$-$+40\%$.

Таким образом, даже несмотря на общее годовое замедление рынка, **четвёртый квартал продолжает демонстрировать самые высокие объёмы кредитований**, что подтверждает сезонный характер спроса и устойчивость канала продаж именно в этот период.

---

### Итоговый вывод:
Рост в IV квартале относительно предыдущих трёх чётко прослеживается каждый год, хотя абсолютная величина годовых показателей снижается. Это позволяет говорить о целесообразности масштабирования работы команды именно в четвёртом квартале, поскольку здесь традиционно наблюдается наиболее высокая активность потребителей.
