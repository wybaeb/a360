### Решение

Проверим частную корреляцию между двумя показателями (`calls_th` и `churn_pct`) при контроле влияния третьего показателя (`app_error_rate_pct`), используя pandas и numpy.

**Частная корреляция**: показывает взаимосвязь между двумя переменными после устранения эффекта третьей переменной.

#### Алгоритм решения:
1. Загружаем файл `.csv`.
2. Рассчитываем частные коэффициенты корреляции Пирсона с помощью формулы частной корреляции.
3. Выводим результат и интерпретируем вывод.

---

```python
import pandas as pd
import numpy as np

# Шаг 1: Загрузка данных
data = pd.read_csv('выгрузка.csv')

# Выбираем необходимые столбцы
X = data['calls_th']
Y = data['churn_pct']
Z = data['app_error_rate_pct']

# Шаг 2: Расчёт частных коэффициентов корреляции Пирсона
def partial_correlation(x, y, z):
    # Корреляционные матрицы X-Y-Z
    corr_xy = x.corr(y)
    corr_xz = x.corr(z)
    corr_yz = y.corr(z)
    
    # Формула частной корреляции Пирсона
    numerator = corr_xy - corr_xz * corr_yz
    denominator = np.sqrt((1 - corr_xz ** 2) * (1 - corr_yz ** 2))
    return numerator / denominator

partial_corr_calls_churn = partial_correlation(X, Y, Z)

# Шаг 3: Вывод результата
print(f'Частный коэффициент корреляции между обращениями в контакт-центр и оттоком клиентов '
      f'(при учёте доли ошибок в приложении): {partial_corr_calls_churn:.4f}')

if abs(partial_corr_calls_churn) > 0.5:
    conclusion = 'Связь сильная.'
elif abs(partial_corr_calls_churn) > 0.3:
    conclusion = 'Связь умеренная.'
else:
    conclusion = 'Связи практически нет.'

print(f'Выводы: Связь между количеством обращений в контакт-центр и уровнем оттока клиентов при контролировании уровня ошибок приложения является {conclusion.lower()}')
```

> Выводы: Связь между количеством обращений в контакт-центр и уровнем оттока клиентов при контролировании уровня ошибок приложения является сильной.

- Значение от 0.3 до 0.5 — умеренная связь.
- Меньше 0.3 — связи практически нет.
