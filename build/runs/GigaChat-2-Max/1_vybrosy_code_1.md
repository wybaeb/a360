Вот реализация проверки на выбросы методом медианы и MAD (Median Absolute Deviation) с подробными пояснениями каждого шага:

```python
import pandas as pd
import numpy as np

# Загрузка данных из csv-файла
df = pd.read_csv('data.csv')

# Рассчитываем медиану столбца 'tat_min'
median_tat_min = df['tat_min'].median()

# Вычисляем абсолютное отклонение от медианы
mad_tat_min = np.median(np.abs(df['tat_min'] - median_tat_min))

# Определяем пороговые значения для робастной Z-оценки 
threshold = 3  # коэффициент масштабирования отклонения (обычно берут значение около 3)
robust_z_scores = (np.abs((df['tat_min'] - median_tat_min)) / mad_tat_min)

# Отбираем наблюдения, превышающие заданный порог
outliers_mask = robust_z_scores > threshold
outlier_count = outliers_mask.sum()  # Количество наблюдений-выбросов

# Выводим результаты анализа
print(f'Количество найденных выбросов: {outlier_count}')
if outlier_count == 0:
    print("Выбросы отсутствуют.")
else:
    print(f"В наборе данных обнаружено {outlier_count} возможных выбросов.")
```

### Пояснение шагов:
1. **Загружаем файл**: используем функцию `pd.read_csv()` для чтения данных из CSV-файла (`data.csv`).
   
2. **Медиана** вычисляется через метод `.median()` для колонки 'tat_min'.
  
3. **MAD (Median Absolute Deviation)** рассчитывается следующим образом:
   - Берём разность между каждым значением и медианой.
   - Используем ещё одну медианную операцию над модулем этой разницы.
   
4. **Робастная Z-оценка**: находим стандартизированные отклонения относительно медианы делённые на MAD.
   
5. **Фильтрация выбросов**: выбираем все точки, где этот показатель превышает определённый порог (здесь установлен равным 3). Чем больше это число, тем менее чувствителен фильтр к выбросам.

6. Подсчёт количества выбросов производится простой суммой булевой маски.

7. Итоговый вывод будет содержать количество выявленных аномалий и короткий комментарий о наличии/отсутствии выбросов.
