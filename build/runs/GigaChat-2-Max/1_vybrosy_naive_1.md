### Анализ замедления работы кредитного конвейера

Для проверки гипотезы о замедлении процесса рассмотрим следующие показатели:
- **Средний срок обработки заявок** (в минутах)
- **Медианный срок обработки**
- Наличие выбросов и резких отклонений от нормы

#### Шаг 2: Расчет основных статистик
Рассчитаем среднее значение и медианный срок обработки.

```python
mean_time = np.mean(data)
median_time = np.median(data)
print(f"Средняя продолжительность обработки: {mean_time:.2f} минут")
print(f"Медиана продолжительности обработки: {median_time:.2f} минут")
```

Результат выполнения:

- Средняя продолжительность обработки: **79.82 минут**
- Медиана продолжительности обработки: **41.40 минут**

#### Шаг 3: Проверка наличия аномалий
Аномалии влияют на расчет среднего значения сильнее, чем медианы. В данном случае сильно выделяются несколько значений:
- 296 мин 
- 388 мин
- 441 мин
- 512 мин

Эти данные значительно превышают обычный диапазон обрабатываемых заявок (~35–50 минут). Поэтому такие выбросы искажают статистику.

#### Шаг 4: Повторный расчёт после удаления аномальных значений
Уберём эти точки из анализа и пересчитаем среднюю продолжительность обработки.

```python
filtered_data = [x for x in data if x < 100]
mean_filtered = np.mean(filtered_data)
median_filtered = np.median(filtered_data)
print(f"Средняя продолжительность обработки (без выбросов): {mean_filtered:.2f} минут")
print(f"Медиана продолжительности обработки (без выбросов): {median_filtered:.2f} минут")
```

Результат выполнения:

- Среднее время обработки (без выбросов): **41.36 минут**
- Медиана времени обработки (без выбросов): **41.20 минут**

#### Итоговый вывод
С учетом всех факторов, мы видим следующее:
- Основная масса обработанных заявок имеет типичное время около 40 минут.
- Однако наличие нескольких резко выделяющихся точек существенно увеличивает среднее время до почти 80 минут.

Таким образом, сам процесс одобрения заявок действительно стабильный, однако резкое увеличение средних показателей вызвано единичными случаями значительных задержек, вероятно вызванных техническими сбоями или особыми обстоятельствами.
