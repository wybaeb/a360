Вот реализация алгоритма поиска выбросов с использованием медианы и среднего абсолютного отклонения от неё (MAD). Этот метод также называют робастной Z-оценкой (`robust z-score`).

```python
import pandas as pd
import numpy as np

# Загрузка данных из csv-файла
data = pd.read_csv('выгрузка.csv')

# Выбираем столбец 'tat_min' для анализа
values = data['tat_min']

# Шаг 1: Рассчитываем медиану значений
median = values.median()
print(f"Медиана срока рассмотрения заявок: {median:.2f} минут")

# Шаг 2: Рассчитываем среднее абсолютное отклонение (MAD)
mad = np.median(np.abs(values - median))
print(f"Среднее абсолютное отклонение (MAD): {mad:.2f}")

# Константа k для определения порога (обычно берут 3 или 5)
k = 3

# Шаг 3: Применяем правило выброса через MAD-значение
threshold = k * mad
outliers = abs(values - median) > threshold

# Выводим количество выявленных выбросов
num_outliers = outliers.sum()
percent_outliers = num_outliers / len(data) * 100
print(f"Выявлено выбросов: {num_outliers}, доля выбросов: {percent_outliers:.2f}%")

# Итоговая строка для отчёта
report_line = f"В результате проверки методом медианы и MAD обнаружено {num_outliers} аномальных значений сроков рассмотрения заявок."
print(report_line)
```

### Пояснения шагов:

1. **Загружаем файл**: Читаем данные из `CSV`, выбираем интересующий нас числовой столбец `tat_min`.
   
2. **Рассчитываем медиану**: Медиана устойчивее к влиянию экстремальных значений (выбросов), чем обычное среднее значение.

3. **Среднее абсолютное отклонение (MAD)**: Это мера разброса вокруг медианы, вычисляемая как медиана модулей разности каждого значения и общей медианы.

4. **Определяем порог выбросов**: Умножив MAD на константу (здесь используем коэффициент $k=3$), получаем пороговое значение, превышающее которое считается выбросом.

5. **Идентифицируем выбросы**: Все точки, чьи отклонения превышают рассчитанный порог, считаются выбросами.

6. **Подсчет количества выбросов**: Определяем число точек, признанных выбросами, и долю выбросов относительно общего числа наблюдений.

7. **Итоговый вывод**: Генерируется отчетная фраза для отчета с указанием найденных выбросов.

---

Таким образом, этот скрипт позволит эффективно выявить потенциальные выбросы среди ваших данных, используя подход, устойчивый к наличию уже существующих аномалий.
