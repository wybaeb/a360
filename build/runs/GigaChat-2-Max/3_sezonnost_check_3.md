# 3. Сезонность: рост, которого нет · GigaChat-2-Max · прогон 3 · check

Вердикт судьи: совпадает с эталоном
Элементы разбора: {"выбрано снятие сезонности": true, "критерий назван": true, "ошибка названа": true}

---

Выгрузка может обмануть тем, что сравнение двух соседних кварталов не учитывает сезонность спроса на кредиты.

Проверка:
1. Снятие сезонности (сравнение год к год), потому что используется некорректное сопоставление временных интервалов.
   
Формула/метод:
2. Рассчитать отношение выданных кредитов IV кв. 2025 к IV кв. 2024 и аналогично для III кв., сравнить полученные коэффициенты роста.

Опровержение / подтверждение:
3. Если рост относительно прошлого года одинаков (+/-5%), вывод неверен. Подтверждение — разные темпы роста по сравнению с прошлым годом.

Типовая ошибка:
4. Проверка позволяет избежать ошибки, связанной с ежегодной цикличностью выдачи потребительских кредитов.
