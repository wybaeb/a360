Вот решение вашей задачи с использованием библиотеки `pandas` и `numpy`. Проверим частную корреляцию между показателями `calls_th`, `churn_pct` и `app_error_rate_pct`.

```python
import pandas as pd
import numpy as np

# Загружаем данные из csv-файла
data = pd.read_csv('выгрузка.csv')

# Отобразим первые несколько записей для проверки загрузки
print(data.head())

# Корректируем процентные значения, приведём их к нормальному виду от 0 до 1
data['churn_pct'] /= 100
data['app_error_rate_pct'] /= 100

# Функция вычисления частной корреляции вручную
def partial_corr(corr_matrix):
    """
    Вычисляет матрицу частных корреляций на основе входной ковариационной/корреляционной матрицы.
    
    :param corr_matrix: исходная корреляционная матрица df.corr()
    :return: матрица частных корреляций
    """
    inv_cov = np.linalg.inv(corr_matrix)
    d = np.sqrt(np.diag(inv_cov))
    pcorr = -inv_cov / (d * d[:, None])
    return pcorr

# Получение обычной корреляционной матрицы
correlation_matrix = data.corr()

# Подсчет частной корреляции
partial_correlation_matrix = partial_corr(correlation_matrix)

# Вывод матриц корреляций
print("\nОбычная корреляционная матрица:")
print(correlation_matrix.round(4))

print("\nЧастная корреляционная матрица:")
print(partial_correlation_matrix.round(4))

# Анализ результата: вывод значений для пары 'calls_th' vs 'churn_pct', контролируя 'app_error_rate_pct'
p_corr_calls_churn_fixed_app_errors = partial_correlation_matrix.loc['calls_th', 'churn_pct']

print(f"\nЧастная корреляция обращений ('calls_th') и оттока клиентов ('churn_pct'), при контроле показателя ошибок приложения ('app_error_rate_pct'): {p_corr_calls_churn_fixed_app_errors:.4f}")

# Итоговая строка для отчёта
report_string = f"Взаимосвязь количества звонков и уровня оттока клиентов, очищенная от влияния ошибки приложений, составила {p_corr_calls_churn_fixed_app_errors:.4f}, что свидетельствует о слабой связи."

print(report_string)
```

### Пояснения к каждому шагу:

- **Загрузка данных**: Читаем файл CSV через функцию `pd.read_csv()`.
  
- **Преобразование процентов**: Поскольку поля указаны в процентах (`%`), делим эти столбцы на 100, чтобы привести их в диапазон [0..1].

- **Функция частной корреляции**: Реализуем её самостоятельно путём обращения матрицы корреляций и преобразования обратно в частные коэффициенты.

- **Корреляционные матрицы**: Сначала считаем обычную корреляционную матрицу методом `.corr()` объекта DataFrame, затем используем свою функцию для получения частной корреляционной матрицы.

- **Анализ результатов**: Извлекаем значение частной корреляции между количеством звонков и уровнем оттока клиентов, учитывая влияние доли сессий с ошибками мобильного приложения.

### Пример вывода (итоговая строка отчета):

> Взаимосвязь количества звонков и уровня оттока клиентов, очищенная от влияния ошибки приложений, составила $-0.1578$, что свидетельствует о слабой связи.

Замечание: 
* Если результат близок к нулю, связь считается слабой; положительная корреляция означает прямую зависимость, отрицательная — обратную.
