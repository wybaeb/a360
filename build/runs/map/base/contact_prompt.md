Управленческий вопрос: Что сильнее снизит нагрузку на контакт-центр: сокращение повторных обращений или перевод типовых тем в бота?

Метрики (название · тип · единица · частота наблюдения):
- Повторные обращения за 7 дней · опережающая · % обращений · наблюдаем ежедневно
- Доля решённых с первого контакта (FCR) · опережающая · % обращений · наблюдаем ежедневно
- Среднее время обработки (AHT) · опережающая · мин. · наблюдаем ежедневно
- Оценка клиента после контакта (CSAT) · запаздывающая · балл из 5 · наблюдаем еженедельно

Источники (система · что даёт · владелец · частота обновления · доверие):
- Телефония · даёт: звонки, очереди, время разговора · владелец: владелец платформы · обновление: в реальном времени · доверие: доверяю
- Тикетная система · даёт: обращения, темы, статусы · владелец: владелец системы · обновление: в реальном времени · доверие: доверяю
- Чат-бот · даёт: диалоги, переводы на оператора · владелец: владелец бота · обновление: раз в сутки · доверие: проверяю
- Опросы после контакта · даёт: оценки CSAT · владелец: владелец опросов · обновление: раз в сутки · доверие: проверяю

Проверка качества:
- разрозненность: звонок, чат и тикет одного клиента не склеены единым ID обращения — повторность считается только внутри канала
- справочники: темы обращений в телефонии и тикетах кодируются разными справочниками

Master-source: показатель «Количество обращений за месяц»; источник A: Телефония: все звонки → 120 тыс.; источник B: Тикетная система: зарегистрированные обращения → 96 тыс.; выбор: Тикетная система — после автосоздания тикета на каждый звонок

Действия (что · кому · срок):
- Ввести единый ID обращения сквозь звонок, чат и тикет — владельцы телефонии и тикетов, срок: квартал
- Свести справочники тем к одному — методолог + владельцы систем, срок: месяц
- Собрать топ-10 тем повторных обращений для передачи боту — аналитик команды, срок: две недели

Формат ответа: по каждой из трёх проверок — короткий вердикт и конкретные строки карты, которые надо исправить; в конце — три самых важных исправления в порядке срочности.
